# Proyecto personal de programación

Repositorio que reúne ejercicios y proyectos desarrollados con C# y .NET durante la formación en Desarrollo de Software.

## Contenido

- Motoconchista: simulación de consola con eventos aleatorios.
- Tarea_Padre_Hija: ejercicio de programación.

## Tecnologías

C# y .NET 8.

## Propósito

Repositorio de práctica personal y académica. Los proyectos más relevantes para procesos de selección profesional están organizados en el repositorio principal de portafolio.

## Estado

Material de práctica; no se presenta como experiencia laboral.
